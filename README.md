# Calculator

A modern calculator built using **HTML**, **CSS**, and **JavaScript**.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Decimal Numbers
- Clear Button
- Backspace Button
- Responsive Layout
- Modern UI

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

```
calculator/
│── index.html
│── style.css
│── script.js
│── README.md
```

## How to Run

1. Download or clone this repository.

2. Open the folder.

3. Double-click **index.html**

or

Open the folder in VS Code and use Live Server.
